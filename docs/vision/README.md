# Aemeath Vision Foundation Pack

Paket fondasi roadmap dan planning untuk mengembangkan image upload, clipboard image paste, dan contextual vision pada Aemeath AI Agent.

**Repository target:** https://github.com/maeshataruna99-lgtm/aemeath-ai-agent

## Isi paket

- `roadmap/ROADMAP.md` — fase, prioritas, dependency, dan definition of done.
- `planning/IMPLEMENTATION_PLAN.md` — rencana teknis bertahap.
- `planning/ARCHITECTURE.md` — rancangan alur data dan batas keamanan.
- `agent/CODING_AGENT_PROMPT.md` — prompt siap diberikan ke AI coding agent.
- `checklists/PHASE_CHECKLIST.md` — checklist dengan status dan bukti.
- `checklists/TEST_MATRIX.md` — test matrix dan acceptance criteria.
- `checklists/DECISION_LOG.md` — keputusan yang harus dikonfirmasi sebelum implementasi.

## Penting

Paket ini adalah **dokumen perencanaan**, bukan implementasi fitur. Tidak ada kode aplikasi yang diubah, tidak ada tes yang dijalankan, dan tidak ada item yang dinyatakan lulus. AI coding agent wajib memeriksa source code terkini dan menjalankan tes sebelum mengubah status checklist.

## Mulai

1. Buka repository dan periksa branch/commit aktif.
2. Baca `roadmap/ROADMAP.md`.
3. Ikuti `planning/IMPLEMENTATION_PLAN.md` secara berurutan.
4. Berikan `agent/CODING_AGENT_PROMPT.md` kepada coding agent.
5. Catat bukti aktual pada checklist setelah setiap fase selesai.
